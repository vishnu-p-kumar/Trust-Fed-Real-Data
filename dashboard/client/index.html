Data protection
  • Raw CSV records are processed in your browser and are not uploaded.
  • The coordinator receives model parameters, feature names, sample count, round ID, and any is_poisoned marker count. It checks model quality against its labeled reference data.
  • The coordinator calculates validation AUC independently; the CSV marker is a reported signal.
  • Browser training uses your signed-in client session; no agent secret or command line is needed.
